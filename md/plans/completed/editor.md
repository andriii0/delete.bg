# Local photo cutout editor

Compare portrait matting and general segmentation on three licensed photographs in a CPU-only browser. Preserve original pixels and dimensions, evaluate matching crops on white and black, and record download sizes and elapsed time.

Build two static entry points with relative URLs. Load inference assets on demand in a worker. Implement reversible alpha editing, aligned preview layers, zoom and pan, and a shared PNG export.

Verify input routes, cache, offline manual edits, pointer gestures, history, clipboard round-trip, subdirectory hosting, and desktop and mobile layouts. Package only the standalone site for Pages.
